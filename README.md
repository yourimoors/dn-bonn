# Disco-Bar D'n Bonn

Nieuwe one-page website voor [dn-bonn.nl](https://www.dn-bonn.nl) (Wilhelminalaan 53, Reusel).

Eén statisch bestand, geen build-stap: open `index.html` of upload het naar de webserver.

## Let op bij live zetten

- Foto's en het logo worden nog geladen van `https://www.dn-bonn.nl/images/…` en `/style/top.png` (oude site). Kopieer die mee voordat de oude site verdwijnt.
- Het logo is uitgesneden uit de oude header (`top.png`). Vervang door een los logobestand (SVG/groot PNG) als dat er is.
- Het contactformulier opent het mailprogramma van de bezoeker (`mailto:`). Voor echt versturen: koppel een dienst zoals Formspree.
- Openingstijden staan in de `HOURS`-lijst onderaan `index.html`.
